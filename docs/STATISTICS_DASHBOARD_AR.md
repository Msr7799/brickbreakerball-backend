# ForgePulse Intelligence — لوحة الإحصائيات

الرابط: `/mcp-dashboard/statistics` على **نفس** مشروع `brickbreakerball-backend` في Vercel.

## من وين تجي الأرقام؟

| القسم | المصدر | التفاصيل |
| --- | --- | --- |
| اللاعبون والجلسات والأحداث | GA4 Data API | خاص بتدفق Android المحدد؛ عدد المستخدمين الإجمالي يُطلب كتقرير مجمّع، وليس مجموع المستخدمين اليوميين |
| الأحداث والإصدارات | GA4 Data API | أكثر الأحداث والإصدارات استعمالًا |
| الأعطال واستقرار اللعبة | Firebase Crashlytics API | appSummary وtopIssues وtopVersions، وعدد الوقوعات والمستخدمين المتأثرين ونسب خلو الأعطال |
| إعلانات التطبيق | AdMob Network Report | الأرباح التقديرية والنقرات والظهور بالعملة الأصلية، وحالة تطبيقات AdMob |
| إعلانات الموقع | AdSense Reports | حتى 30 يومًا عند اختيار فترة 90 يومًا، مع بيان الفترة في القسم |
| مشتريات التطبيق | MongoDB `events` | إشعارات RTDN المسجلة فقط؛ لا تُحوّل إلى قيمة مبيعات، لأن المبالغ لا تُخزن هنا |
| أداء MCP | MongoDB `mcp_audit` | نجاح وفشل واستعمال الأدوات والخدمات عبر الفترة المحددة |
| تغطية 55 أداة | `toolsMeta` و`mcp_checks` | عدد الأدوات للقراءة والتعديل وحالة آخر فحص للخدمات، وليس تشغيل الأدوات الـ55 تلقائيًا |

التقرير يدعم 7 و30 و90 يومًا. تواريخ MongoDB تُجمع بتوقيت البحرين، وتواريخ GA4 تعتمد منطقة الخاصية. كل قسم يعرض انقطاع الصلاحية أو عدم توافر البيانات بدل أرقام وهمية.

## الحماية

- تستعمل الصفحة جلسة Admin الحالية نفسها (HttpOnly + Secure + SameSite Strict).
- `GET /api/mcp-control/statistics` يعيد 401 قبل أي استعلام لغير المدير، مع `no-store`.
- كل عمليات جلب الإحصائيات للقراءة فقط؛ لا تستعمل أدوات تغيير بيانات Google.
- لا تُرسل رموز OAuth أو مفاتيح الخدمة إلى المتصفح؛ والأخطاء تُختصر ويُحجب منها ما قد يكون حساسًا.
- الصفحة نفسها تحمل `robots: noindex, nofollow`، بينما البيانات لا تخرج إلا من API محمي.

## ما لا تقيسه هذه النسخة

- زيارات موقع Vercel نفسه تختلف عن جلسات Android في GA4. تحتاج Web Analytics أو تتبع ويب منفصلًا ومصرحًا به إذا تريد زوار الموقع.
- Crashlytics لا يوفر بالضرورة نفس فترة وعدد مستخدمي GA4، فلا تجمع العدادات عبر المصدرين.
- Google Play Developer API يعيد 403 في فحص صلاحية `playCaller` الحالي؛ حالة الخدمة تظهر عند الفحص، لكنها لا تُعامل على أنها نجاح افتراضي.
- اختبارات `MCP_WRITE_ENABLED` وأدوات الإدارة لا تُنفّذ أثناء فتح صفحة الإحصائيات.

## التحقق

من جذر المستودع:

```bash
pnpm exec tsc --noEmit
pnpm test:logic
pnpm build
```

ثم التحقق من أن الطلب بدون جلسة Admin إلى `/api/mcp-control/statistics?days=7` يرجع 401، وأن المدير يرى كل قسم مع حالة مصدره بعد النشر.
